# Етап II — кваркова фаза MIT Bag і перевірка SLy4

Цей каталог містить результати числового моделювання **холодної кваркової матерії** у спрощеній моделі MIT Bag з трьома **безмасовими** ароматами кварків `u`, `d`, `s`. Взаємодії між кварками, крім феноменологічної сталої мішка, не враховані. Речовина в β-рівновазі та локально електронейтральна. Це модельне наближення, а не доведення наявності кваркових ядер у реальних нейтронних зорях.

## Як відтворити

Потрібні `Python`, `numpy`, `scipy`, `pandas`, `matplotlib`, а також оригінальний `eos.zip` (CompOSE RG(SLy4) #134). Виконайте з каталогу з файлами:

```bash
python stage2_quark_phase.py eos.zip results
```

## Формули

Усі хімічні потенціали в `MeV`, тиск і густина енергії в `MeV/fm³`, баріонна густина в `fm⁻³`.

- `ħc = 197.3269804 MeV·fm`.
- `B[MeV/fm³] = (B^(1/4)[MeV])⁴ / (ħc)³`.
- `P_Q(μ_B) = μ_B⁴ / [108π²(ħc)³] − B`.
- `n_{B,Q}(μ_B) = μ_B³ / [27π²(ħc)³]`.
- `ε_Q(μ_B) = 3P_Q + 4B`.
- `c_s²/c² = dP/dε = 1/3`.
- `μ_{B,0} = [108π²(ħc)³B]^(1/4)` при `P_Q=0`.

У моделі **всі шість варіантів мають однаковий нахил `P(ε)`**. Величина `B` змінює зсув рівняння стану і точку появи додатного тиску.

## Перевірки

- Для SLy4 перевірено `ε + P = μ_B n_B` та `dε/dn_B ≈ μ_B`.
- Максимальна відносна нев'язка першої тотожності на сітці: `0.0113 %`.
- Медіанне відхилення чисельної похідної `dε/dn_B`: `0.0032 %`, максимальне `0.316 %` на краю сітки.
- Обчислення `dP_H/dμ_B` чутливі до різких змін нахилу біля `n_B≈0.044 fm⁻³` (там можливі до ~18% локальні відхилення дискретної похідної). Це не доказ порушення тотожності, а попередження щодо диференціювання грубої сітки.
- У кварковій моделі тотожності `ε_Q+P_Q=μ_B n_{B,Q}` та `n_{B,Q}=dP_Q/dμ_B` виконуються аналітично. Перевірено також чисельно.

## Перетини (кандидати для побудови Максвелла)

Порівняння `P_H(μ_B)` та `P_Q(μ_B)` здійснено в **межах** фактичної SLy4-таблиці; для тиску SLy4 використано монотонну PCHIP-інтерполяцію, перетини знайдено методом Брента.

- `B^(1/4)=145,155 MeV`: у табличному діапазоні кварковий тиск вищий за адронний на всіх μ_B. Отже, звичайної межі адронна оболонка → кваркове ядро для цих параметрів немає.
- `165 MeV`: перетин є, але при дуже малому `P_t` та надзвичайно великому стрибку енергії. Трактувати його як доказ стійкого кваркового ядра не можна.
- `175,185,190 MeV`: математичні перетини знайдені, їх параметри наведені в CSV.

**Важливо:** жодної залежності маса–радіус, максимальної маси чи зоряної стійкості тут ще не обчислено. Це задача для наступного етапу (гібридна EoS та рівняння TOV). Зокрема, наявність перетину не гарантує існування стійких гібридних зір.

## Файли

- `SLy4_thermodynamic_audit.csv` — перевірки 197 адронних точок.
- `MIT_Bag_parameters.csv` — шість значень `B`, хімічний потенціал, баріонна густина і густина енергії при нульовому тиску.
- `MIT_Bag_quark_EoS.csv` — числові дані *додатного тиску* кваркової фази для кожного `B`.
- `MIT_Bag_Maxwell_candidates.csv` — перетини фаз, густини та стрибки енергії.
- `01_*` ... `06_*` — шість графіків для роботи МАН.
- `calculation_summary.txt`, `metadata.json`, `run_log.txt` — вихідні підсумки і метадані.
- `stage2_quark_phase.py` — відтворюваний код у корені ZIP-архіву.

На графіках `P_Q(μ_B)` криві математично подовжені на область `P_Q<0` для порівняння з адронною фазою; в експортованій числовій EoS кварків ця область відсутня.
