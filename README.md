# Original research scripts

These are the original numerical scripts supplied in the research archive, preserved for traceability. They have not been rewritten, and keep their original imports and output paths. The preferred readable implementation lives in `../quarkmatter/` and `../run_analysis.py`.

To run the original programs, place the input `eos.zip` from the original archive alongside these scripts, and execute them in their original documented order. This archived code is not the primary public API.
